# SCS 术后程控与随访系统

疼痛科脊髓电刺激（SCS）术后程控的触点覆盖模拟与随访系统。Vue 3 + 原生 SVG，单页应用，无需构建、无需联网（Vue 已本地化为 `vendor/vue.global.prod.js`），数据保存在浏览器 localStorage。

## 运行

直接用浏览器打开 `index.html` 即可（推荐 Chrome/Edge）。首次打开可在页面底部点击「载入演示数据」查看完整流程。

## 五个模块

| 模块 | 功能 |
|---|---|
| 📋 植入登记 | 患者信息、电极型号（8 触点单列 / 16 触点双列）、植入节段（T1–L2 多选）、左右侧；保存后自动生成触点布局 |
| 🎛️ 电极配置 | SVG 画布按节段排布触点；点击触点循环切换 关闭→阴极→阳极；每触点电流 0–100% 可调，**总电流超过 100% 直接拦截**并红框提示 |
| 🗺️ 覆盖模拟 | 皮节带人体图上按电流强度高斯扩散叠蓝色；点击皮节带标记患者疼痛区（橙色）；自动计算重合率，**<60% 提示更换极性/触点组合**；方案可存为 A/B/C 程序组（含参数与覆盖率快照）；覆盖图可导出 SVG |
| 📝 程控记录 | 程控单：日期、技师、程序组、参数变化、VAS、逐触点阻抗；状态流 草稿→已实施→已复核，**复核可退回并写意见**；历次程控 VAS/重合率对比折线图；**阻抗异常（<400 或 >2500Ω、较上次变化>30%）或覆盖率变化>20% 自动标红，提示怀疑电极移位**；可导出 CSV / JSON |
| 📈 随访评价 | 随访录入（VAS、满意度、异感覆盖、备注）、VAS 趋势图（术前+程控+随访合并）、**按医师统计 VAS 下降情况**（平均下降、有效率≥50% 人数、条形图） |

## 角色权限（右上角切换）

- **疼痛科医师**：全部功能 + 植入登记 + 程控单复核/退回
- **器械技师**：电极配置、覆盖模拟、程序组、程控单录入
- **随访护士**：随访录入

## 计算规则

- 覆盖权重：触点电流按高斯函数（σ≈2 个皮节）向上下皮节扩散，阴极权重 1.0、阳极 0.7，同带叠加
- 重合率 = Σ min(1, 疼痛带覆盖权重/0.35) ÷ 疼痛带数量 × 100%
- 电极移位警示：阻抗越界或较上次变化 >30%，或重合率较上次变化 >20 个百分点
