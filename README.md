# 跨线人行天桥方案比选与净空校核系统

面向高速公路跨线人行天桥方案设计的桌面 Web 应用：SolidJS + three.js，支持多方案建模、强制性净空/墩位校核、梯道坡度提示、并排技术经济比选、公路部门审核流程与审定后交付物生成。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5199
```

其他命令：

```bash
npm run typecheck  # TypeScript 严格检查
npm run build      # 生产构建（dist/）
npm test           # 55 项校核/计量/审核流单元测试
npm run e2e        # 16 项浏览器交互测试（需先 npm run dev）
```

## 业务规则

| 规则 | 判定 | 级别 |
| --- | --- | --- |
| 桥下净空（梁底高程 − 路面高程）< 5.0m | `CLEARANCE_LOW` | ⛔ 错误，禁止提交 |
| 净空 5.0–5.5m | `CLEARANCE_TIGHT` | ⚠️ 警告（富余不足） |
| 墩身投影与行车道（含硬路肩）重叠 | `PIER_IN_LANE` | ⛔ 错误，禁止提交 |
| 墩身投影与管线保护范围重叠 | `PIER_IN_PIPELINE` | ⛔ 错误，禁止提交 |
| 梯道坡度陡于 1:4 / 坡道陡于 1:10 | `SLOPE_STEEP` | ⚠️ 警告提示 |
| 任一侧未布置接入设施 | `APPROACH_MISSING` | ⚠️ 警告 |

存在任一条 ⛔ 错误时，提交按钮锁定，store 的 `submit()` 也会二次拦截。错误构件在三维场景中标红、警告标黄。

## 功能清单

- **输入与建模**：交叉处路面高程、车道数/车道宽/硬路肩/分隔带；可选钢箱梁或混凝土箱梁（自动切换默认梁高与指标）；桥跨、梁底高程、桥宽参数化
- **构件布置**：梯道、坡道、电梯按左右侧布置；桥墩可表格精确输入，也可在三维视图中沿桥跨方向**拖拽布墩**，实时校核
- **三维场景**（three.js）：道路横断面与车道线、管线保护带、主梁/桥面/栏杆、桥墩承台、阶梯式梯道、坡道、电梯井；净空虚线标注、构件标签、退回意见 💬 气泡
- **自动计量**：钢材（型钢+钢筋）、混凝土、造价、占地、封闭施工天数，全部为响应式派生
- **多方案比选**：并排表展示造价/净空/钢材/混凝土/占地/工期，自动标注各行最优项与禁报方案
- **审核流**：提交 → 公路部门受理 → 退回（意见挂靠具体构件，场景中显示气泡，可标记整改）或审定通过（记录审定人、日期）
- **交付物**（仅审定通过后）：技术交底图 SVG（立面+横断面+尺寸+净空）、构件清单 CSV、各方案钢材用量统计与 CSV 导出
- **持久化**：全部方案与审核记录存 localStorage，刷新不丢失

## 目录结构

```
src/
├── types.ts                 领域类型
├── store.ts                 Solid Store：多方案/审核流/持久化
├── lib/
│   ├── constants.ts         定额指标、单价、控制标准
│   ├── engine.ts            道路几何、净空/墩位/坡度校核、计量
│   ├── factory.ts           方案工厂与内置示例
│   ├── deliverables.ts      交底图 SVG / 清单 CSV / 钢材统计
│   └── engine.test.ts       规则测试（24 项）
├── three/Scene3D.ts         three.js 场景、拾取、拖拽、标红
├── components/              Solid UI（参数编辑/右栏校核/弹层/比选）
└── App.tsx                  三栏布局组装
```

> 造价与工期采用方案阶段估算指标（见 `src/lib/constants.ts`），可按地方定额直接调整。
