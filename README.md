# 高速公路深路堑边坡防护布置与验收批次系统

基于 **TypeScript + 原生 WebGL2** 的深路堑边坡三维防护设计与施工验收一体化 Web 应用，无需任何三维引擎，着色器、相机、拾取与场景图均为手写实现。

## 功能

### 三维边坡生成
- 按**坡率（1:n）、分级高度、平台宽度**逐级生成台阶式边坡三维面；
- 按**地质分层**（土 / 岩，层底高程）对坡面顶点着色，直观呈现覆盖层、风化带与基岩；
- 自动计算每级坡面坡顶/坡脚线、倾向、外法线、斜长与**土岩分界线**。

### 防护构件布置（设计员）
- **锚杆框架梁**：沿走向按 **6m 自动分块并与坡顶线（x=0）对齐**，沿倾向按排距生成节点网格，竖梁+横梁自动成架；
- **锚杆长度随岩层变化**：每个节点按其高程所处岩土层取该层锚杆标准长度，杆体沿坡面法线锚入；
- **土岩分界提示加密**：分界线落在两排锚杆之间时给出警告，一键在分界处插入加密排并对上下段重新等距排布；
- **同级坡上下排锚杆间距不一致直接报错**，并给出等距排距建议；
- **截水沟**：坡顶截水沟 / 平台截水沟，梯形断面；
- **护面墙**：坡面两点圈定走向区间，半透明覆盖；
- **监测点**：位移监测桩 / 深部位移孔 / 地下水位孔 / 锚索测力计，带三维编号标签。

### 工程量统计
实时汇总并分级展示：
- 锚杆**根数**与钻孔总延米（按岩层分别统计）；
- **混凝土方量**（框架梁、截水沟、护面墙分列）；
- **钢筋吨位**（框架梁按配筋率 + 锚杆杆体按单位重）；
- 一键**导出工程量清单 CSV**（UTF-8 BOM，Excel 直接打开）。

### 验收批次流转（角色切换）
- **施工班组**按分级、按构件类型申报验收批次，自动编号 `P级-序号`，锁定申报时工程量快照与计划工期；
- **监理**逐批**签认合格**或**退回整改**（退回必须填写整改说明）；
- 班组整改后可重新申报，自动重算应完成日期；
- 含设计规则错误的分级禁止申报；
- **看板**：批次总览、各级坡完成比例进度条、**超期批次**清单与超期天数。

### 其他
- 三角色切换（设计员 / 施工班组 / 监理），不同角色开放不同操作；
- 项目 JSON 导入导出、localStorage 自动存档；
- 轨道相机：左键旋转、右键平移、滚轮缩放、双击复位；射线拾取与悬停岩层提示。

## 技术栈

| 模块 | 实现 |
| --- | --- |
| 语言 | TypeScript（strict） |
| 渲染 | 原生 WebGL2（手写 GLSL 300 es、VAO/VBO、光照与雾、透明混合） |
| 数学 | 自写 vec3 / mat4 / 射线-平面求交 |
| 构建 | Vite 6 |
| 测试 | esbuild 打包的单元规则测试 + puppeteer-core 端到端工作流测试 |

## 目录结构

```
src/
  core/        领域模型与业务规则（几何、设计引擎、验收、导出、状态仓库）
  renderer/    WebGL2 渲染器、相机、场景控制器与拾取
  ui/          左右面板、模态框、提示
  types.ts     领域类型
test/
  smoke.ts     33 项核心规则单元测试
  e2e.mjs      端到端工作流测试（需本机 Chrome）
```

## 运行

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5180
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产包
npm run typecheck  # 仅类型检查
npm run test:unit  # 核心规则单元测试
npm run test:e2e   # 端到端测试（先启动 dev，并安装 Chrome）
```

## 关键业务规则实现位置

- 6m 分块与坡顶线对齐、排距校验、分界加密：`src/core/engine.ts`
- 锚杆长度随岩层：`buildFrame()` 中 `layerAtElev` + 层 `anchorLength`
- 边坡/地质三维面与土岩分界：`src/core/geometry.ts`
- 批次申报/签认/退回/超期/完成比例：`src/core/acceptance.ts`
- 工程量与清单导出：`src/core/export.ts`
