# 眼科 OCT 断层分层渲染与随访进展判读平台

SolidJS + WebGL2 实现的门诊 OCT 随访工作台。支持 B 扫描灰度断层渲染、视网膜分层（ILM / GCL / 筛板）手动修正、厚度地形图、双眼对称分析、随访差分闪烁与进展判读工作流。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173（端口被占用时自动顺延）
npm run build      # 生产构建
npm run typecheck  # TypeScript 类型检查
npm test           # 核心逻辑冒烟测试（32 项：分层/断裂/5µm 标红/工作流/审计/模板）
```

## 角色与职责

| 角色 | 权限 |
| --- | --- |
| 技师（李技师） | 设备导入、设备台账、自动分层、分层模板维护、提交判读 |
| 门诊医师（王医师） | 拖拽修正分层、厚度图/差分闪烁分析、进展判定（进展/稳定/可疑 + 必填依据） |
| 主任医师（张主任） | 待审队列逐例审核厚度曲线与标红象限、审核通过、退回重新分层、统计与导出 |

右上角可随时切换身份。所有数据保存在浏览器 localStorage，可用顶栏「重置演示数据」恢复种子数据。

## 随访单工作流

```
待分层 pending_layers ──自动分层+提交──▶ 待判读 pending_review ──医师判读──▶ 已判读 interpreted
        ▲                                                                    │
        └──────────────────── 主任填写退回原因 ◀────────────────────────────┘
                                   已退回 returned
```

每次改动（导入、自动分层、手动修正、提交、判读、退回、模板维护）都写入该访视单的审计日志，记录操作人与时间，可在详情页「操作审计」查看，并随进展报告导出。

## 核心功能

- **WebGL2 断层渲染**：B 扫描以 LUMINANCE（R8）灰度纹理渲染，含散斑噪声、深度衰减、边界高反射与筛板阴影；三条分层线以 GLSL 着色器叠加，可勾选显隐。
- **拖拽修正**：在分层线 14px 容差内按下即可拖动，途经列连续吸附；双击标记/修复断裂（null 与邻近插值互切），断裂处以红叉标示。
- **厚度地形图**：ILM–GCL 神经节细胞复合体厚度（µm）Canvas 热力图，四象限（颞上/鼻上/颞下/鼻下）分割，断裂点红叉、异常象限红框。
- **双眼对称图**：同次访视 OD/OS 四象限厚度并列，差值绝对值 >5µm 标不对称。
- **差分闪烁**：同帧位置本次/上次 B 扫描按 300/700/1200ms 交替，可手动定格单侧。
- **自动标红规则**：象限平均厚度较上次变薄 ≥5µm，或该象限存在分层断裂点，即在地形图与象限表标红。
- **判读**：医师必须三选一（进展/稳定/可疑）并填写依据才能提交。
- **导出**：单患者 HTML 进展报告（结论、依据、象限差分、标红、审计）与 CSV 厚度趋势表。
- **统计**：按患者统计进展率（判进展次数/已判读次数）、总体进展率、退回原因分布。

## 演示数据

真实环境的 OCT 像素文件/DICOM 导入由设备接口提供；本演示用确定性种子程序化生成 64 帧 × 256 A扫描 × 256 深度的灰度体数据（轴向 2µm/px、横向 4µm/px），同一访视可完全复现。导入面板可指定厚度变化（负值模拟变薄）与断裂位置，用于验证标红与退回流程。种子患者包含：基线稳定、随访进展（变薄+断裂）、已退回、待分层等完整场景。
