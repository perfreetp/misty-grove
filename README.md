# TAVR 规划台

心内科结构性心脏病小组的**主动脉瓣置换(TAVR)术前测量与虚拟释放系统**。
React 18 + TypeScript + WebGPU,影像与测量数据全部保存在浏览器本地(IndexedDB),不经过任何服务器。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run check      # TypeScript 类型检查
```

浏览器需支持 WebGPU(Chrome / Edge 113+)。顶栏的 `WebGPU` 指示器会显示渲染后端是否就绪;
若不可用,三维与多平面重建面板会给出明确提示,其余流程(测量口径、型号库、审核、统计)仍可正常使用。

## 角色

顶栏右侧可切换三个角色,同一份本地数据,权限按角色收敛:

| 角色 | 可做 |
| --- | --- |
| 介入医师 | 勾画测量、选型号、虚拟释放、填写偏离理由、提交审核、查看统计 |
| 技师 | 维护瓣膜型号库与测量口径(阈值、过度扩张区间等) |
| 主任 | 待审队列审核/退回、复核测量值与钙化热区、生成术前讨论单、查看统计 |

## 工作流

```
待测量 ──提交──▶ 待审核 ──通过──▶ 已通过 ──▶ 术前讨论单
   ▲                 │
   └──── 需复核 ◀────┘ 退回
```

1. **申请单** — HIS 同步或手工新建;导入 CT 序列(DICOM 或内置体模)。
2. **测量台** — 多层轴位勾画瓣环,自动重建三维瓣环;勾画 LVOT;长轴视图标记左右冠开口与主动脉/左室轴线;测量入路管径。
3. **虚拟释放** — 从型号库选瓣膜,瓣架按径向力做网格变形;自动比对冠脉净距与瓣周漏风险区,超口径时标黄并要求填写偏离理由。
4. **审核** — 主任查看测量值、成角、钙化热区、偏离理由,可退回重测或通过(可修正最终型号用于统计)。
5. **术前讨论单** — 通过后生成,含 WebGPU 三维截图与测量摘要。
6. **统计** — 按术者统计型号一次选准率、退回次数、平均过度扩张等。

## 关键实现说明

- **瓣环重建**:多层轮廓做 PCA 平面拟合,按角度重采样后做最小二乘椭圆拟合;
  周长用 Ramanujan 椭圆近似并对鞍形三维偏移做弧长修正,面积为平面投影面积。
  在理想勾画下,合成的 27.0×22.4 mm 瓣环重建周长误差 < 0.5 %。
- **瓣环壁校准**:轮廓按"内缘"口径绘制后,沿径向采样 HU 寻找血池-壁交界,修正量被限制在 ±0.9 mm,
  避免把瓣环推到外膜。
- **钙化分布**:瓣环平面上下 ±6 mm 带内按 HU 阈值统计,分 36 个扇区;
  钟点按患者轴位平面(12 点=前方)换算,与 CT 阅片习惯一致。
- **虚拟释放**:瓣架在瓣环带受管壁约束(钙化越重撑开越少),离瓣环后松弛至名义直径,
  上方受主动脉窦/窦管交界限制,下方受 LVOT 限制;贴合间隙与欠膨胀率由此得出。
  冠脉净距取冠脉开口高度处瓣架表面到开口中心的径向距离。
- **三维渲染**:WebGPU 自写渲染管线(MSAA、深度、逐层着色);
  钙化用 Surface Nets 提取等值面(比 marching cubes 更适合此处,无查表错误风险),
  并做连通域过滤去掉噪声点。
- **截图**:直接从 GPU 纹理 `copyTextureToBuffer` 回读,画布 `drawImage` 对 WebGPU 交换链不可靠。

## 数据与隐私

- 申请单、测量、审核、统计保存在 IndexedDB `tavr-planning-station` 的 `state` 库;
- CT 体素保存在同一数据库的 `volumes` 库,按序列 ID 存放;
- 全部数据仅在本机浏览器内,刷新/重启不丢失,清除站点数据即清除;
- 顶栏显示本地已用存储量。

## 目录

```
src/
  lib/        几何、测量、虚拟释放、类型定义
  data/       DICOM 解析、合成体模、种子数据、IndexedDB
  render/     WebGPU 场景、三维网格、Surface Nets、窗宽窗位
  components/ 切片视图、三维画布、图标、通用 UI
  pages/      申请单、测量台、虚拟释放、待审队列、型号库、统计、讨论单
  workers/    体模生成(避免阻塞主线程)
tools/        Playwright 回归脚本与数据生成脚本
```
