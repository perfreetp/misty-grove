# 高速公路服务区危化品车辆分区停放与巡查系统

基于 **Three.js（r128）** 的纯前端三维可视化系统，无需构建工具、无需后端，
数据通过浏览器 `localStorage` 持久化，库文件已本地化到 `vendor/`，可完全离线运行。

## 运行方式

```bash
# 任选一种静态服务器方式
python -m http.server 8765
# 然后浏览器打开 http://localhost:8765/index.html
```

> 直接双击 `index.html` 也可运行（localStorage 与本地脚本均为同源可用）。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 应用入口，顶栏 / 侧边栏 / 三维视口 / 弹窗骨架 |
| `styles.css` | 深色主题、面板、表单、图表、告警条等全部样式 |
| `app.js` | 全部业务逻辑：三维场景、合规引擎、登记计时、告警、巡查、处置、看板、导出 |
| `vendor/` | 本地化的 three.min.js / OrbitControls / TransformControls |

| `test-plan.html` | 俯视平面图与不合规标红的可视化验证页 |

## 三类角色与功能

### 服务区管理员
- **分区布置**：在三维地面点击落位新增危化品 / 普通货车 / 小车分区；开启布置模式后
  可用 TransformControls 平移、旋转分区与加油站、餐厅；可调整每个分区车位数、删除空分区。
- **合规校验（规则可配置）**：
  - 车位数量下限（默认危化品 6、货车 10、小车 15），不足时标红并提示“还差 N 个”；
  - 危化品车位到加油站（默认 ≥30 m）、餐厅（默认 ≥25 m）的实测最小距离，
    不达标时该分区在三维视图中红色脉冲闪烁，并给出实测值与下限。
- **车辆登记**：车牌、介质、押运人（危化品必填），自动分配同类型空闲车位并开始计时；
  支持手动指定分区（用于演示停错区域），可调整车位、车辆离场。

### 巡查员
- 按白班 / 夜班自动判定班次，选择车位、上传现场照片（自动压缩）打卡；
- 标记“异常”的条目自动生成告警并转**应急处置单**；
- 巡查记录可按班次、状态筛选。

### 主管
- 当日**占用率、超时率、告警平均处置时长**、今日告警 / 入场 / 巡查打卡等指标；
- 车位类型环形图、分区占用率条形图、告警分类图；
- 导出中心：巡查记录 CSV、车辆登记 CSV、**俯视分区平面图 PNG**（含标题、合规状态、指北针）。

## 告警与处置闭环

- 超时未离场：扫描器按虚拟时钟检测，超过 `maxStayMinutes` 自动生成告警；
- 停错区域：登记 / 调位时车辆类型与分区不符即告警，纠正分区或车辆离场后自动关闭；
- 巡查异常：自动转应急处置单；
- 处置单回填处置人与结果后闭环，关联告警同步关闭并记录处置时长。

## 演练辅助

顶栏提供 **1× / 60× / 600× / 3600× 模拟倍速**，可在几十秒内演练完整的
“入场 → 超时告警 → 转单 → 处置回填”流程；“重置演示数据”可一键恢复初始场景。
