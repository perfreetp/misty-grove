# 匝道控制配时仿真台

高速公路入口匝道（单点定时控制）的配时编辑、信号与检测器布设、排队/主线速度仿真，以及方案
「草稿 → 试运行 → 生效 → 停用」全生命周期管理。纯前端实现（HTML + CSS + Canvas2D + 原生 JS），
直接用浏览器打开 `index.html` 即可运行，数据保存在浏览器 `localStorage`。

## 快速开始

```
# 直接双击 index.html，或本地起一个静态服务
npx serve .
```

推荐使用 Chrome / Edge 最新版，窗口宽度 ≥ 1280 获得三栏布局；窄屏自动变为上下堆叠。

## 功能对照

| 需求点 | 实现位置 |
| --- | --- |
| 选一条入口匝道 | 顶栏「当前匝道」下拉，内置 R-07 / R-12 / R-03 / R-09 四条匝道，各自独立方案集与日志 |
| 设定主线与匝道流量、占有率阈值、周期 | 左侧「控制参数」：主线上游流量、主线占有率阈值、主线限速/车道数、匝道需求流量、排队容量、匝道占有率阈值、饱和流率；周期/绿信比用滑块 |
| 平面图上摆信号灯与检测器断面 | 画布工具栏「放置信号灯」「布置检测器断面」，点击匝道/主线即布置；「选择 / 移动」下可拖动设备、点选设备查看浮层并删除（Delete 键同效） |
| 拖动周期与绿信比观察排队与主线速度 | 拖动滑块即时重算理论放行率/饱和度，仿真引擎按新参数继续运行，画布中排队长度、主线车流速度随之变化 |
| 排队溢出到主线变红并提示缩短周期 | 排队超过匝道容量即触发：匝道车辆与断面变红、合流区红色晕染、顶部红色横幅提示建议的周期与绿信比，并提供「采纳建议配时」 |
| 四状态流转 | 右侧「方案流转」步骤条与按钮：草稿可编辑 → 提交试运行 → 确认生效 / 退回草稿 → 停用；草稿、试运行状态下参数与设备锁定策略不同 |
| 试运行记录实际占有率与偏差 | 试运行按仿真时钟 5 分钟，每 30 秒采样一次，记录实际占有率、主线速度、实测周期/有效绿与方案偏差，并汇总判定是否通过 |
| 生效后锁定并留操作人与时间 | 生效后所有输入禁用、设备不可编辑；「锁定人 / 锁定时间」显示在状态卡片，同时写入控制日志；停用同样留痕 |
| 值班长一键切换默认方案 | 右上「切换为值班长」后启用「一键切换默认方案」：按中心缺省配时 C=60s、g/C=0.45 新建方案并立即生效，原生效方案自动停用、进行中的试运行中止，全程留痕 |
| 导出配时表与当日控制日志 | 顶栏「导出配时表」（方案一览 + 当前方案明细 + 试运行采样）、「导出控制日志」（当日全部匝道操作记录）；均为带 BOM 的 UTF-8 CSV，可直接用 Excel 打开 |

## 仿真模型（简化）

- 匝道单车道，信号控制：有效绿 `g = round(C × g/C)`，黄灯 2s，其余为红灯；每周期启动损失 3s。
- 理论放行率 `s × (g − 3) / C`；绿灯初期按 2s 渐变模拟启动损失，其余时段按饱和流率放行。
- 匝道排队 `q ← q + 到达 − 放行`，到达为泊松扰动后的需求流量。
- 溢出：`q > 排队容量` 触发；回溢影响（`spill`）扩散快、消退慢，降低主线有效通行能力并压低主线速度。
- 主线速度/占有率：由主线上游流量、汇入流量、车道数与回溢影响计算负荷，做指数平滑；负荷超过 0.6 后速度快速下降。
- 界面 1 秒 ≈ 10 秒仿真时间；「单步 30s」用于逐段观察。

模型用于配时方案比选与操作流程演练，不作为通行能力精确计算依据。

## 目录结构

```
index.html        页面骨架
css/app.css       全部样式（含响应式与主题色）
js/data.js        匝道路网档案、方案模型、种子数据、localStorage、CSV 导出
js/engine.js      排队/放行/主线速度仿真、调节建议、试运行判定
js/stage.js       Canvas2D 平面图渲染、设备布置与拖拽、缩放平移、趋势小图数据
js/ui.js          参数绑定、仿真循环、方案流转、日志、弹窗、导出
```

## 操作提示

- 空格 开始/暂停仿真；`Delete` 删除选中设备；`Esc` 关闭弹窗 / 取消选中 / 退出布置模式。
- 画布滚轮缩放（1×–2.6×），拖动空白处平移，双击复位。
- 方案处于试运行/生效/停用状态时参数锁定，需「新建调整草稿」后再编辑。
- 「全局重置」：浏览器控制台执行 `localStorage.removeItem('ramp-metering-sim.v2')` 后刷新，恢复示例数据。
