# 高架桥下空间利用方案编排与联审系统

Vue3 + WebGL2 纯前端应用，数据保存在浏览器 localStorage。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能

- **净空模型**：输入跨径布置与各墩位桥面标高，按 `净高 = 桥面标高 − 主梁高度 − 地面标高` 生成桥下净空模型；净高 < 3m 区段自动标红，禁止摆放构件。
- **平面编排**：从构件库拖拽停车位 / 篮球场 / 绿化带 / 配电箱到桥墩之间；构件自动避让桥墩（净距 0.3m），实时校验净高与重叠，非法位置自动还原。
- **三维净空**：WebGL2 渲染主梁（变高程）、桥墩、地面网格、构件、红色禁摆区与消防通道，支持旋转缩放。
- **消防通道**：全桥纵向连续通道净宽实时计算，不足 4m 时拦截提交联审。
- **联审流程**：初稿 → 联审 → 批复三状态；城管 / 消防 / 养护三方（右上角切换角色）把意见挂在具体构件上；任一方退回即封存当前版并生成下一版初稿，历史版本可回看。
- **统计**：桥下面积利用率、停车位数量、投资估算（含明细）。
- **导出**：带标注平面图 PNG（随时可导）、批复单（批复完成后可导，可打印/另存 PDF）。
- **发布控制**：未走完批复流程，"对外发布"按钮禁用。

## 目录

```
src/bridge.js   桥梁几何与净空模型
src/rules.js    避让/校验/消防通道/统计规则
src/store.js    方案、版本与联审流程状态
src/gl/scene.js WebGL2 三维渲染器
src/export.js   批复单与平面图导出
src/components/ 界面组件
```
