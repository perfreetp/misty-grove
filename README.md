# 疼痛科脊柱介入穿刺路径三维规划与审签系统

基于 **Vue 3 + three.js** 的单页应用,全部数据保存在浏览器本地(localStorage + IndexedDB),无需后端。

## 运行

```bash
npm install
npm run dev      # 开发: http://127.0.0.1:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

## 角色与流程

右上角切换身份(预置用户):

| 角色 | 职责 |
|---|---|
| 接诊医师 | 新建病例(疼痛节段/责任神经根/既往手术史/凝血指标)→ 导入CT、透视影像 → 三维模型上点击标记椎体/椎间孔/神经根 → 拖拽穿刺针调整外展角、头倾角、进针深度 → 提交审签 |
| 介入技师 | 在「模板维护」按节段维护穿刺模板与入路偏好(入路方式、默认角度、侧别、备注) |
| 主任医师 | 在「审签台」比对三维路径与影像切层,可「审签通过」或「退回」并填写退回原因 |

病例状态流转:**待规划 → 待审签 → 已通过 / 已退回**(退回后医师可修改并重新提交),每次状态变更均记录操作人、角色与时间(见规划页「操作记录」)。

## 安全联锁

系统实时计算针尖到**最近神经根**与**硬膜囊**的距离,任一距离 **< 3mm** 时:

- 视口红色闪烁告警,针尖变红;
- 「提交审签」按钮被禁用,直到路径调整安全。

## 功能一览

- **三维规划**:程序化腰椎模型(L1–L5 + 骶骨、椎间盘、硬膜囊、双侧神经根、椎间孔),OrbitControls 旋转缩放,点击拾取解剖结构,拖拽针体调角度,滑块微调。
- **术前交底单**:审签通过后在病例列表点「交底单」,含路径截图、角度参数、安全距离、操作记录与签字栏,可直接打印。
- **统计分析**:按节段统计送审次数、通过数、一次通过率(首次提交即通过),以及退回原因分布。
- **本地存储与导出**:病例/模板存 localStorage,影像存 IndexedDB;支持导出全部或单个病例为 JSON(影像内嵌 base64)交给手术组,也可再导入。

## 目录结构

```
src/
  spine.js                 # three.js 场景:脊柱模型、穿刺针、距离计算、拾取
  store.js                 # 响应式状态、持久化、工作流动作、导入导出
  db.js                    # IndexedDB 影像存取
  components/
    NeedleView.vue         # 三维视口(规划/审签共用)
    CaseList.vue           # 病例列表
    CaseForm.vue           # 新建病例
    PlannerView.vue        # 规划台(影像、标记、进针参数、提交)
    TemplatesView.vue      # 模板维护(技师)
    ReviewView.vue         # 审签台(主任)
    BriefingSheet.vue      # 术前交底单(可打印)
    StatsView.vue          # 统计分析
```

> 说明:三维脊柱为程序化示意模型,用于路径规划流程演示,非真实患者解剖数据。
