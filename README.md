# ESD 病变边界增强与术前讨论系统

面向消化内镜黏膜下剥离术（ESD）的术前工作站：内镜截图导入、WebGL2 着色器增强、病变边界圈定、按比例尺测量、病理取材对账、上级医师讨论退回，全流程数据保存在浏览器本地。

## 技术栈

- **原生 TypeScript + WebGL2**，无 UI 框架、无运行时第三方依赖
- Vite 构建，GLSL ES 3.00 片段着色器
- IndexedDB 持久化（病例、截图 Blob、预设、比例尺标定）
- Canvas 2D 叠加层完成多边形标注

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npx tsx tests/geometry.test.ts   # 测量/对账单元测试
```

## 角色与功能

| 角色 | 功能 |
| --- | --- |
| 内镜医师 | 新建病例、导入白光 WLI / 窄带 NBI 截图、调增强、圈定病变/抬举/切开线、登记取材块、提交讨论、接收退回后修改 |
| 技师 | 维护增强参数预设（含假彩色 3×3 矩阵）、比例尺标定管理 |
| 上级医师 | 待讨论列表中比对增强前后图像与边界叠加、通过或退回（必填原因）、通过后导出讨论单 |

### 状态流转

```
待标注 drafting ──提交──▶ 待讨论 pending ──通过──▶ 已通过 approved
                              └──退回──▶ 已退回 returned ──接收修改──▶ 待标注
```

提交前校验：至少一张截图、病变范围、计划切开线、比例尺标定、取材对账通过。

## WebGL2 增强管线

`src/webgl/EnhanceRenderer.ts` 中的片段着色器分五段：

1. 对比度（围绕中灰 0.5）
2. 明度去相关 / 饱和度增强
3. 9 抽头拉普拉斯型高频提取 → 血管增强（G 通道额外加权，适配 NBI）
4. 绿色通道强调
5. 3×3 假彩色通道混合矩阵（行主序存储，上传前转列主序）

内置四套预设：标准白光、NBI 血管增强、靛胭脂染色模拟、醋酸染色模拟。滑块调整 uniform 后即时重绘。

## 标注与测量

- 三类多边形：**病变范围**（红）、**抬举试验边界**（绿）、**计划切开线**（黄），坐标全部归一化（0..1）
- 绘制：逐点单击、双击闭合、右键取消；编辑：拖动顶点、双击边线插入顶点
- 测量：归一化多边形先变换到 mm 物理坐标，再用旋转卡壳求最小外接矩形（长径/短径），鞋带公式求面积，正确处理图像宽高各向异性
- 比例尺：图上画已知长度参考线段，换算 mm/像素

## 取材对账规则

- 块总面积 < 切开范围面积 → 红色警告「取材盖不住切开线」
- 最长取材块 < 病变长径 → 红色警告长径方向可能漏切
- 任一不满足则对账不通过，禁止提交讨论

## 讨论单导出

通过后导出单张 PNG：病例信息头、增强图 + 三类边界叠加、长径/短径/面积、取材块数与对账结论、退回原因与流程审计记录。

## 统计

- 按医师：提交讨论数、被退回数、**边界修改率**（被退回病例 / 提交病例）
- 按预设：各增强预设使用次数（应用预设时累加）
- 病例状态分布

## 数据与隐私

所有截图、标注、病例元数据仅写入浏览器 IndexedDB，不发起任何网络请求；清除浏览器站点数据即全部删除。
