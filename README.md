# 山区高速公路长下坡避险车道选址与制动床验算系统

Svelte + three.js 实现的避险车道选址与验算工具。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建到 dist/
```

## 功能

- **纵断面导入**:粘贴或选择 CSV,每行 `桩号,坡度(%),坡长(m)[,平曲线半径(m)]`,桩号支持 `K12+500` 或 `12500`;导入后由 three.js 渲染连续下坡三维地形(山体、主线、公里桩),底部同步显示纵断面图。
- **选址布设**:点击"沿主线布设"后在三维主线上点击放置避险车道;拖动引道口锥标沿主线调整位置;型式可选 **上坡式 / 砂床式 / 网索式**。
- **制动床验算**:按设计车型、载重、制动失效初速度、制动床纵坡与滚动阻力系数计算
  `L = V² / (254 × (f + i))`,向上取整至 5m 并按 **≥120m** 控制;宽度按车型(超重加宽)。
- **标红规则**:场地可用长度不足(至下一处避险车道/连续下坡终点/路线终点)或 **入口视距被 R<450m 弯道遮挡** 时,三维场景与面板同步标红,提示挪位置或换型式;存在标红时禁止提交联审。
- **审批流程**:拟定 → 联审(养护科+交警)→ 批复 → 已建成,支持退回修改;每次创建、移动、改参、换型、状态流转均自动留 **修订记录与计算依据**。
- **统计**:相邻避险车道间距、分段覆盖里程与覆盖失控车辆数(失控车辆密度可调)、分项工程量汇总。
- **导出**:一键导出《避险车道选址论证表》CSV(Excel 可直接打开)与含修订记录的方案 JSON。

数据保存在浏览器 localStorage,刷新不丢失;右上角"重置"恢复示例纵断面。
