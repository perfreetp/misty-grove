# BoardDocs Studio · 开发板装配与引脚说明制作平台

面向教学开发板厂商的交互式内容制作平台：在 WebGL2 场景里导入开发板分层模型、编排拆装步骤、给引脚打热点并填写名称 / 电压 / 复用功能，走完「提交评审 → 逐条批注 / 退回 → 通过 → 生成对应固件版本的说明版本 → 发布 → 基于版本开修订」的完整流程。

纯前端实现，无构建步骤、无外部依赖，数据保存在浏览器 localStorage。

## 运行

```bash
# 任意静态服务器即可（ES Module 需要 http 协议）
python -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```

推荐最新版 Chrome / Edge / Firefox（需要 WebGL2）。

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 型号 | 4 个演示型号的卡片：引脚数、已标注比例、功能冲突、审核时长、未标电压数量、当前流程状态 |
| 编辑 | 三栏场景编辑器：图层 / 装配步骤 · WebGL2 场景 · 引脚 / 步骤 / 版本面板 · 冲突与发布检查 |
| 评审 | 评审队列、发布检查阻断项、引脚与步骤逐条批注、解决/重新打开、通过 / 退回 |
| 发布 | 已发布版本快照（只读）、版本时间线、交付物导出、开修订 |
| 统计 | 按型号汇总引脚数量、已标注比例、平均审核时长，可导出 CSV |

### 场景编辑（WebGL2）

- 自研 WebGL2 渲染器（`js/gl.js`）：分层板卡几何、地面网格、平行光 + 高光 + 菲涅尔、雾、透明外壳排序、分步拆装的位移/透明度动画、屏幕投影拾取。
- **导入分层模型**：按外壳 / 主板 / 屏蔽罩 / 接口 / 显示模块等类型生成独立图层，可逐层命名、改类型、调颜色、缩放与位移、拖拽调整堆叠顺序、显隐。
- **打点**：工具栏「＋ 打点」后在主板上点击新增引脚热点；点击已有热点即可选中。
- **分组高亮**：右侧分组胶囊（电源 / GPIO / 通信 / 模拟 / USB / 调试 / 启动 / 显示）多选高亮，其余热点自动淡出。
- **引脚标注**：名称、电压、分组、所在图层、备注、复用功能列表。同一引脚重复填写同一功能时，行内立即标红并在底部「功能冲突」中同步提示（含一键去重）。
- **装配步骤**：新增 / 复制 / 删除 / 上下移动 / 拖拽排序，指定动作（安装 / 拆卸）、涉及零件图层与提示文字；也可按图层「自动」生成拆卸步骤。
- **分步播放**：编辑器内直接按步骤播放（零件升起 / 下沉 + 高亮），或打开全屏预览。

### 预览

全屏预览支持两种模式，可随时切换：

- **分步播放**：底部步骤缩略图条 + 播放 / 暂停 / 上一步 / 下一步 / 进度滑杆，每步显示动作类型与提示文字。
- **自由查看**：自由旋转缩放，点击热点查看引脚详情卡（名称、电压、分组、所在图层、复用功能、冲突提示）。

### 评审与发布

- 提交审核时展示发布检查结果；草稿随即锁定为「待审核」，不可直接编辑。
- 评审员逐条批注（可关联到具体引脚 / 步骤 / 整体），编辑在下一轮可见「上一轮 · Rev N」的遗留批注。
- 通过前必须处理完批注，且**不能存在未标电压的阻断项**；退回必须写原因，退回后草稿恢复可编辑。
- 通过后由评审员生成发布版本：填写对应固件版本与变更说明，生成只读快照并进入版本时间线。
- 发布后不可直接修改，只能「基于该版本开修订」（新草稿继承快照内容、修订号 +1、固件版本自动递增）。

### 发布检查

- **阻断项**：未标注电压的引脚（发布与评审通过都会被拦下）。
- **提醒**：同一引脚功能重复占用、引脚缺少复用功能、步骤未指定零件、尚未编排步骤。

### 导出（售后 / 课程组）

- **引脚清单 CSV**：序号、名称、电压、分组、所在图层、复用功能、重复占用、备注（UTF-8 BOM，Excel 可直接打开）。
- **装配步骤图 SVG**：按步骤排版，含零件爆炸缩略图、动作标记、涉及零件标签与操作提示，可打印进课程讲义。
- **说明包 JSON**：引脚、图层、步骤与版本元数据，供下游系统对接。
- **型号汇总 CSV**：统计页导出各型号的引脚数量、标注比例、审核时长等。

## 目录结构

```
index.html          外框、顶栏、侧栏
css/app.css         设计系统与所有页面样式
js/main.js          路由、顶栏状态、全局命令
js/store.js         数据模型、校验（冲突 / 发布检查）、流程状态机、种子数据
js/gl.js            WebGL2 渲染器（矩阵、着色器、几何、相机、拾取）
js/preview.js       分步播放 / 自由查看预览
js/export.js        CSV / SVG / JSON 导出
js/publishDialog.js 发布对话框
js/views/*.js       型号、编辑器、评审、发布、统计页面
```

## 数据与重置

数据在首次打开时写入 localStorage（键 `boarddocs.studio.v1`）。顶栏「数据」菜单可导出 JSON 备份、导入备份或恢复演示数据。
