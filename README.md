# 高速公路改扩建导改渠化方案编排与审批系统

基于 Vue3 + Canvas2D 的高速公路养护作业交通组织方案编制工具,供养护工程部编制、报审、实施导改渠化方案使用。

## 运行

```bash
npm install
npm run dev      # 开发环境,默认 http://localhost:5173
npm run build    # 生产构建,输出 dist/
npm run preview  # 预览生产构建
```

## 功能模块

### 1. 路段档案
- 录入主线车道数(单向)、设计速度(120/100/80)、桩号范围
- 中央分隔带开口位置(名称+桩号,用于导改借道)
- 施工工期(起止日期,联审通过后作为撤除日期依据)

### 2. 渠化编排(Canvas2D 画布)
- 按桩号在画布上布设锥桶、水马、施工围挡、限速标志(120/100/80 三级)
- 拖拽落位自动吸附车道线,限速标志自动落于右侧路肩外
- 实时合规校验,不合规项当场标红并给出建议值:
  - 渐变段长度按设计速度计算(L=0.625·V·W),不足标红
  - 锥桶间距(渐变段≤4m,其余≤10m)、水马≤2m、围挡≤3m
  - 封闭车道数不得超过 N-1(至少保留一条行车道)
  - 限速按 120→100→80 逐级衔接,相邻落差>20km/h 拦截
  - 预告距离(120→300m、100→200m、80→100m)不达标拦截
  - 作业区限速须降至 80km/h 及以下
- 存在不合规项时禁止提交联审

### 3. 联审流转
- 编制人提交后,交警、路政双方并联审批
- 退回必须填写意见,全部流转动作留痕(时间/角色/动作/意见)
- 双方均通过后自动生成实施版本号与撤除日期

### 4. 实施台账
- 已通过方案台账:实施版本、工期、撤除日期、阶段状态(待实施/实施中/超期未撤除/已撤除)
- 监控中心分幅封道图(每幅 500m),与编辑器共用同一渲染器,图面与现场一致
- 导出渠化图 PNG、锥桶/水马/围挡/限速标志数量清单 CSV
- 撤除确认留痕

## 角色

右上角切换角色:编制人(可编排/提交)、交警、路政(可审批)、监控中心(台账查看)。数据保存在浏览器 localStorage。

## 规范参数

阈值集中在 `src/rules.js` 顶部,依据《公路养护安全作业规程》(JTG H30)思路设置,可按项目要求调整。
