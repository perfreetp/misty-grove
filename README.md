# Capsule Station · 胶囊内镜图像序列阅片与报告发布工作台

消化内镜中心的胶囊内镜（小肠镜）阅片工作台，覆盖「登记导入 → 时间轴阅片 → 病灶标注 → 报告审核 → 阅片统计」全流程。原生 TypeScript + Canvas 2D + IndexedDB，无前端框架、无后端服务，数据保存在本机浏览器，刷新不丢。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5612
npm run build      # 类型检查 + 生产构建
npm run test:e2e   # Playwright 端到端测试
```

首次打开会写入 5 条演示检查单（待阅片 / 阅片中 / 待审核双阅 / 已发布含更正草稿 / 已退回各一条）。左下角「重置演示」可随时恢复。

## 五个模块

### 1. 登记导入
- 受检者姓名 / 性别年龄 / 适应证 / 备注，可选双人阅片。
- 图像序列来源两种：
  - **演示序列**：程序化生成 1800 帧胶囊内镜影像。
  - **导入本地图像帧**：拖拽或选择 JPG/PNG/WebP，按文件名自然排序，至少 4 帧，帧数据写入 IndexedDB。
- 登记后检查单进入「待阅片」，编号 `CE-年份-序号` 顺延。

### 2. 时间轴阅片
- Canvas 2D 逐帧渲染，`←/→` 逐帧、`Shift+←/→` 十帧、`空格` 播放暂停、`[`/`]` 调速。
- 播放速度 0.125× / 0.25× / 0.5× / 1× / 2× / 4× / 8×，慢放与快放都到 8 倍。
- **遇到标记帧自动停顿**：播放跨越病灶帧或关键帧时精确停在那一帧并提示肠段，可关闭。
- 时间轴滑杆拖动定位，显示帧号与时间码；三角旗为病灶帧，圆点为关键帧。
- 胃肠分段用不同底色区分（食管 / 胃 / 十二指肠 / 空肠 / 回肠 / 结肠），**分段边界可拖动修正**，修正后记录改动人姓名与时间，时间轴与分段列表都会标出。
- 阅片时长按真实停留时间累计（暂停研读同样计入，切到其他标签页不计），持久化后刷新继续累加。
- 播放速度与「标记帧自动停顿」开关作为本机偏好保存在 localStorage。

### 3. 病灶标注
- 在影像上拖动框选病灶，四角可调整；类型四选一：出血 / 溃疡 / 息肉 / 血管畸形。
- 估计大小（mm）必填，可快捷选 3/5/8/12/20。
- 每个病灶生成/绑定**关键帧**，绑定到具体时间点与所在肠段；同一帧重复绑定会被拦下。
- 列表实时标出「大小为空」「缺关键帧」，未补齐的病灶无法提交。

### 4. 报告审核
- 阅片结论按阅片人分别展示与编辑；双人阅片时**并列列出两人结论差异**，不一致会在审核区高亮提示。
- 提交前置校验，任一病灶缺关键帧、大小为空，或阅片结论为空，都会弹出明细拦截，并可一键跳到病灶标注补全。
- 双人阅片需两人都提交才进入「待审核」。
- 审核医师可发布或退回；**退回必须填写意见**，退回后检查单回到「已退回」并计入退回次数。
- **已发布报告修改**：发起更正需填写原因，生成新版本草稿（原版本保留为历史版本）。更正期间病灶、分段与结论重新解锁可编辑；更正送审后由审核医师把关，通过后旧版标记为 superseded，版本列表完整保留 v1、v2 及取代关系。更正被退回时仍作为草稿保留，原发布版本继续有效，阅片人可修改后重新提交。
- 可导出报告文本；操作轨迹记录每一次登记、绑定、提交、审核、退回与更正。

### 5. 阅片统计
- 平均阅片时长（按阅片人次）、病灶检出数与阳性率、退回率、已发布/待审核计数。
- 状态分布环形图、阅片时长条形图、病灶类型与肠段分布。
- 检查单明细表可点击跳转到对应检查单，另含检出 TOP 与双人阅片一致性。

## 数据与持久化

- IndexedDB 数据库 `capsule-station`，四个对象仓库：`exams`（检查单、分段、病灶、关键帧、报告版本、评估）、`audit`（操作轨迹）、`frames`（导入的图像帧）、`assets`（关键帧图像）。
- 所有写入即时落库；读取时对旧记录做字段归一化，升级不会破坏已有数据。
- 影像帧本身是程序化生成，只存种子与帧数；导入的帧才存二进制，因此演示数据几乎不占空间。

## 结构

```
src/
  main.ts          应用外壳：顶栏、检查单列表、筛选、身份切换、模块路由
  store.ts         全部业务规则与持久化编排（登记、阅片、标注、审核、更正、统计）
  db.ts            IndexedDB 封装
  frames.ts        Canvas 2D 帧渲染与图像源（含导入帧缓存）
  texture.ts       黏膜纹理预生成（按肠段/种子缓存，播放期零额外开销）
  timeline.ts      时间轴组件：分段泳道、滑杆、边界拖拽、标记帧
  ui.ts            html 模板、图标、Toast、模态框、焦点保持
  views/           五个模块视图
  styles/          设计令牌与布局
tests/             Playwright 端到端测试（13 条，覆盖全流程与持久化）
```
