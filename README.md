# 钟面 · 宫颈阴道镜病灶标注与活检随访系统

面向阴道镜医师、病理对接护士、随访专员三方协作的单页应用。以「宫颈钟面」为共同语言，把检查登记、图像标注、活检瓶号、病理回填、随访对比串成一条可追溯的流水线。

技术栈：Svelte 5（runes）+ Canvas 2D + Vite，纯前端，数据保存在浏览器 localStorage。

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物在 dist/
```

## 五个模块

| 模块 | 使用者 | 说明 |
| --- | --- | --- |
| 检查登记 | 随访专员 / 医师 | 新建检查单、预约日期、按状态看板与队列 |
| 图像标注 | 医师 | 醋酸前 / 醋酸后 / 碘染三图并排，钟面轮廓标注 |
| 活检点位 | 医师 | 图上点选 1—4 个取材点，自动生成瓶号与部位描述 |
| 病理回填 | 病理护士 | 逐瓶回填 CIN 分级，与图像点位联动核对 |
| 随访对比 | 随访专员 / 医师 | 两次图像半透明对齐、面积对比、随访任务与结案 |

另附「统计」页：各医师活检阳性率（CIN1+ / CIN2+ 可切换）。

## 检查单流转

```
待检查 → 已检查 → 待活检 → 已出病理 → 随访中 → 已结案
```

每一步都有服务端的等价守卫（`src/lib/domain.js` 的 `guardAdvance`），不满足条件时前端直接拦住并给出原因：

- 进入「已检查」：三张图像齐全，且已标注病灶或填写「未见异常」说明。
- 进入「待活检」：至少 1 个、至多 4 个点位，瓶号与部位描述均已生成。
- 进入「已出病理」：每瓶都有病理分级与报告日期。
- **结案：病理未填全一律拒绝**，且随访任务须全部完成。

## 钟面标注

- 钟面为**检查者视角**：12 点朝上，3 点对应患者左侧。象限划分为左前 / 左后 / 右后 / 右前。
- 添加病灶时选定「起点 → 终点」的钟面跨度与内外径，系统生成扇环轮廓；随后可拖动整体、拖顶点改形状、双击边缘加顶点。
- 每个病灶自动计算：钟面跨度与**累及周长百分比**、累及象限、标注面积（mm²）；周长百分比可手动覆盖。
- 转化区按「宫颈口内圈 = 新 SCJ、外圈 = 原始 SCJ」的双圈模型判定，输出「转化区内 / 越过内界 / 越过外界 / 跨越转化区」四态。标定比例默认原始 SCJ 直径 30 mm，可在设置中按实际大小调整。

## 活检与病理

- 瓶号规则：`检查编号-B序号`，如 `C-2026-1104-B2`；删除点位后自动重新编号。
- 部位描述由点位自动推导：`8点方位 · 右后象限 · 距宫颈口约 9mm · 转化区内`。
- 病理回填时选中瓶号，图上对应点位高亮；两张表双向可点。
- **标黄复核**的触发条件：
  - 阳性点位（CIN1 及以上）落在所有标注病灶轮廓之外；
  - 病理级别高于镜下病灶分级（如镜下低级别、病理 CIN2）；
  - 取材不足 / 无法评价；
  - 高级别病灶未获病理证实；
  - 与前次相比病灶面积增大（≥5% 或 ≥5 mm²）。

## 随访

- 「已出病理」后按最高分级推荐复查间隔（CIN2/3、AIS 为 3 个月，CIN1 为 6 个月等），生成到期任务。
- 到期任务可一键「检查到期」，按计划任务去重生成当次随访任务，重复点击不会重复生成。
- **改约必须填写原因**，原约日期、新日期、操作人、原因全部写入任务历史与病案日志。
- 两次检查影像可半透明叠加（含前次轮廓，青色虚线），并给出面积变化与百分比。

## 布局

- 宽屏三图并排；容器宽度小于 620 px 时自动切为单图显示，右下角按钮切换醋酸前 / 醋酸后 / 碘染，轮廓与点位在三张图间保持同一坐标。
- 导航按角色过滤：随访专员看不到图像标注与活检，护士不能提交检查结论，结案仅医师可操作。

## 报告

随访页「图文报告」提供三图、钟面示意图、病灶表、活检病理表、与上次对比、随访计划与结案小结，可在新窗口打印或下载 HTML 后用浏览器另存 PDF。

## 数据

- 首次打开载入 10 例演示病案（含 1 例面积增大、1 例点位与病理不符、1 例病理部分回填），影像为程序合成的示意图像，**不含任何真实患者数据**。
- 所有修改自动写入 localStorage。演示数据可通过清空站点数据恢复。
- 导入图像会压缩至最长边 1400 px 的 JPEG 以控制存储占用。
